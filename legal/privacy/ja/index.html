本プライバシーポリシー（以下「本ポリシー」）は、Izure（いずれ。以下「本アプリ」）における、本アプリ利用者（以下「利用者」）の情報の取り扱いについて定めるものです。本アプリは Sota Sugiyama（ハンドルネーム mon50）が個人として開発・運営しています（以下「当方」）。

本アプリは、利用者が置いた一片の記録（本アプリでは「半券」と呼びます）を端末内に保存し、利用者が半券を開いたときに、その半券に紐づく材料をもとに読み物を生成します。本ポリシーでは、この動作にあたって何をどこへ送るかを、実装にもとづいて記載します。

1. 取得する情報

当方は、本アプリの動作に必要な範囲で次の情報を取り扱います。

1.1 端末内に保存される情報

次の情報は、利用者の端末内の SQLite データベースに保存されます。当方のサーバーには保存されません。

  • 利用者が入力した、または他のアプリから共有した本文そのもの。
  • 本文から取り出した URL と、そのホスト名。
  • 本アプリが本文につけた題・要約・分類。
  • 利用者が半券に書き足した一言（本アプリでは「判」と呼びます）。
  • 本アプリが生成した読み物（catch-up）と「続きの種」、およびその生成に用いたモデル名。
  • 半券どうしをまとめた「束」の対応関係。
  • 利用者が半券に設定した通知の時刻、半券を切った時刻、削除の状態。
  • 旧バージョンで作成されたチャット履歴・リマインダーのデータが残っている場合は、それも同じデータベース内にあります。

このデータベースには、本アプリ独自の暗号化を適用していません。保護は端末の OS が備えるディスク暗号化に依存します。詳細は §6 をご覧ください。

次の情報は、OS が備える安全な保管領域（iOS の Keychain / Android の Keystore）に保存されます。

  • 表示モード、アクセント色、通知の設定、オンボーディングの完了状態。
  • 匿名の端末識別子（§1.3）。
  • 課金状態のキャッシュ（有効・無効、満了日、購入した商品の識別子）。
  • 本アプリがサーバーへの接続に用いるアクセストークン。

1.2 読み物の生成のためにサーバーへ送信される情報

本アプリは、次の操作にあたって、インターネットを通じて当方の運用するサーバー（Cloudflare Workers 上のステートレスなエンドポイント）へ情報を送信します。

  • 半券を置く操作: 利用者が入力した、または他のアプリから共有した本文そのもの、本文から取り出した URL（最大 2 件）、および端末のローカル時刻（タイムゾーンのずれを含みます）。
  • 半券を開いて読み物を生成する操作: 当該半券の URL と題（単体のとき最大 3 件、束のとき最大 12 件）、置いたときの本文（最大 2,000 文字）、利用者が書いた「判」の日付と本文、 同じころ（前後 7 日）に置いた他の半券の題とその識別子（最大 8 件）、および束を構成する半券の情報。
  • 「続きの種」を生成する操作: 置いたときの本文、利用者が書いた「判」、同じころに置いた他の半券の題。

当方のサーバーは、受け取った情報を OpenAI 社の API（大規模言語モデル）へ転送し、生成された結果を利用者の端末へ返します。当方のサーバーは受け取った内容を保存しません。 OpenAI 社における取り扱いは §4.2 に記載します。

送信しないもの: 本アプリは、利用者と AI とのやりとりの履歴、過去に保存した記録の要約、および画像を、サーバーへ送信しません。

1.3 通信に付随して送信される識別子

§1.2 の通信には、次の情報が付随します。

  • 匿名の端末識別子: 本アプリが初回起動時に生成するランダムな UUID です。氏名・メールアドレス・ストアのアカウント・広告識別子とは結びつきません。無料枠の回数制限と、短時間に集中した要求の抑制のために用います。当方のサーバー側に残るのは、この値をハッシュ化した 8 文字の文字列だけで、元の値は復元できません。
  • 現在のプラン種別（無料 / 有料）。無料枠の回数制限の判定に用います。
  • 本アプリ共通のアクセストークン。当方のサーバーが本アプリからの要求であることを確認するためのもので、利用者ごとに異なる値ではなく、利用者を識別する情報を含みません。

1.4 端末の権限

  • 通知: 利用者が半券に時刻を設定したとき、その時刻に通知するため、通知の権限を求めます。通知はすべて端末内で予約されるローカル通知であり、当方のサーバーから送るプッシュ通知ではありません。通知の本文には、その半券の題が含まれます。通知は本アプリの設定からいつでも停止できます。
  • 写真ライブラリ・カメラ: 本アプリはこれらの権限を宣言しており、ストアの権限一覧に表示されます。ただし、2026-09-22 時点のバージョンには、利用者が画像を選択または撮影する画面がありません。そのため、権限の確認画面が表示されることはなく、画像が当方のサーバーへ送信されることもありません。将来のバージョンで画像を扱う機能を追加する場合は、本ポリシーを改訂したうえで提供します。
  • 位置情報・連絡先・マイク・通話履歴: 権限を宣言しておらず、取得しません。

1.5 他のアプリからの共有（共有シート）

Android 版では、他のアプリの共有メニューから本アプリへテキストや URL を渡せます。このとき本アプリの画面は開かず、渡された文字列は端末内のファイルに一時的に預かられます。預かった内容は、次に本アプリを開いたとき、または本アプリに戻ったときに読み出され、半券として端末内のデータベースに保存されるとともに、§1.2 の「半券を置く操作」としてサーバーへ送信されます。読み出しが終わると、預かりファイルは削除されます。

共有元のアプリが渡す題（Android の EXTRA_SUBJECT）は、本文と重複する場合に本アプリ側で取り除きます。受け取る種別はテキストのみで、画像は受け取りません。iOS 版にはこの機能がありません。

利用者が第三者の投稿やページを共有した場合、その内容が §1.2 および §3.2 の流れで当方のサーバーおよび OpenAI 社へ渡ります。第三者の権利に関わる取り扱いは 利用規約をご確認ください。

1.6 課金・サブスクリプションに関する情報

利用者が有料プラン「Izure Pro」を購入する場合、決済そのものは Apple App Store / Google Play が処理します。当方は、購入状態（サブスクリプションの有効・無効、満了日）を管理するため、購入レシート、ストアが発行する購入識別子、および RevenueCat が自動生成する匿名のアプリ内ユーザー ID（氏名等の本人識別情報とは結びつきません）を、処理者である RevenueCat（§4.1 参照）へ送信します。当方および RevenueCat は、利用者のクレジットカード番号その他の決済情報を取得・保持しません。

本アプリにログイン機能はなく、購入状態はストアのアカウントに紐づきます。無料トライアルは提供していません。

1.7 当方が取得しない情報

  • 氏名、住所、電話番号、生年月日、性別、メールアドレス等の登録情報（本アプリにアカウント機能はありません）。
  • IDFA / Advertising ID 等の広告識別子。
  • クラッシュレポートや解析ツール（Firebase / Crashlytics / Google Analytics / Sentry 等）を介した利用状況。本アプリはこれらの SDK を組み込んでいません。
  • 広告 SDK。本アプリに広告はありません。

2. 利用目的と法的根拠

  • §1.2 で送信された情報は、利用者へ示す読み物・題・要約を生成する目的にのみ利用します。
  • §1.3 の識別子は、無料枠の回数制限、短時間に集中した要求の抑制、およびプラン種別の判定にのみ利用します。
  • §1.6 の情報は、購入状態と利用権限の管理にのみ利用します。
  • 当方は、機械学習モデルの学習・改善、広告配信、第三者へのプロファイル提供、その他の二次利用を一切行いません。

法的根拠（GDPR）: §1.2・§1.3・§1.6 の取り扱いは、利用者が求めたサービスの提供に必要なものであり、契約の履行を法的根拠とします（GDPR Art. 6(1)(b)）。

3.2 利用者が貼った URL の取得

利用者が置いた本文に URL が含まれている場合、当方のサーバーが、その URL の宛先サイトへ直接アクセスし、ページの題・説明文・本文を取得します。取得した内容は、題をつけるため、および読み物を生成するための材料として OpenAI 社の API へ渡されます。

  • アクセスは利用者の端末からではなく、当方のサーバーから行われます。利用者の IP アドレスは宛先サイトへ渡りません。
  • 半券を置くときは最大 2 件、読み物を生成するときは最大 3 件（束のときは最大 12 件）の URL を取得します。
  • 取得する本文の長さには上限を設けています（半券を置くときは約 1,200 文字、読み物を生成するときは最大 24,000 文字）。
  • 取得先が応答しない場合、内容が HTML またはプレーンテキストでない場合、取得は行わずに処理を続けます。
  • 宛先が localhost やプライベート IP アドレス、標準以外のポートである場合、取得を行いません。
  • X（旧 Twitter）については公開の syndication エンドポイント（取得できない場合は公開の oEmbed エンドポイント）、YouTube については公開の oEmbed エンドポイントを用います。
  • 取得したページの内容は、当方のサーバーには保存されません。

3.3 URL の取得にあたって当方のサーバーが名乗る情報と、取得の範囲

§3.2 の取得にあたり、当方のサーバーは、次の名前（HTTP の User-Agent ヘッダ）を宛先サイトへ伝えます。他のサービスのクローラやブラウザの名前を名乗ることはありません。

Izure/1.0 (+https://mon50.github.io/izure-legal/)

括弧内の URL は、本アプリの法的情報のページです。宛先サイトの管理者が、どこからの取得かを確かめ、当方へ連絡できるよう添えています。

取得は、次の範囲に限って行います。

  • 利用者が置いた URL だけを取得します。利用者の操作を起点としない取得は行いません。
  • 1 つの URL につき 1 回だけ取得します。取得できたかどうかの結果は利用者の端末に保持し、同じ URL を繰り返し取得しに行くことはありません。
  • 巡回は行いません。取得したページに含まれるリンクをたどることはありません。
  • 宛先が localhost やプライベート IP アドレス、標準以外のポートである場合は取得しません（§3.2）。

当方は、宛先サイトの robots.txt を参照しません。robots.txt は RFC 9309 が「クローラと呼ばれる自動クライアント」に向けて定める仕組みであり、同文書は「これらの規則はアクセス権限の付与の形式ではない」とも述べています。上記のとおり、当方の取得は巡回ではなく、利用者がご自身で置いた 1 本の URL を、その求めに応じて 1 回取得するものです。

宛先サイトの管理者の方で、当方からの取得をお断りになりたい場合は、§9 の連絡先までお知らせください。当方において当該サイトからの取得を停止します。

ログインの要求、ページの削除、その他の理由でページの内容を取得できなかった場合、当方はその内容を用いずに処理を続けます。読み物を作るための材料が揃わない場合は、その旨を本アプリの画面に表示します。

4. 第三者処理者と外国への提供

4.1 第三者処理者

当方は、本アプリの動作に必要な範囲で、利用者から送信された情報を次の第三者処理者へ転送します。これらは当方が委託する処理者であり、独立した提供先ではありません。

  • OpenAI, L.L.C.（所在地: アメリカ合衆国）
    • 用途: 題・要約・読み物・「続きの種」の生成。
    • 転送される情報: §1.2 の本文・URL・題・「判」・他の半券の題と識別子、および §3.2 で取得したページの内容。
    • 取り扱いの詳細は §4.2。
  • Cloudflare, Inc.（所在地: アメリカ合衆国）
    • 用途: 当方のサーバー（Cloudflare Workers）の実行基盤。
    • 当方は Cloudflare 上に利用者の本文を保存していません。保存しているのは §5.2 のカウンタとログのみです。
  • RevenueCat, Inc.（所在地: アメリカ合衆国）
    • 用途: 有料プラン（サブスクリプション）の購入状態・利用権限の管理。
    • 転送される情報は購入レシート、ストアの購入識別子、匿名のアプリ内ユーザー ID に限られ、半券の本文や本人識別情報は含まれません。

上記以外の第三者（広告主、データブローカー、外部企業）に対し、利用者の情報を販売・譲渡・共有することはありません。

4.2 OpenAI 社におけるデータの取り扱い

OpenAI 社が公開する API のデータ管理に関する文書によれば、API を通じて送信された内容は、利用者が明示的に同意しない限り、同社のモデルの学習・改善には利用されません。当方はこの同意を行っていません。

一方で、同社は不正利用の監視のため、API を通じたやりとりの記録を最大 30 日間保持する場合があります。この期間を過ぎた記録は、法令上の保持義務がある場合を除いて同社のシステムから削除されます。したがって、当方のサーバーが内容を保存しないことと、OpenAI 社の側に一定期間の記録が残りうることは、別の事柄です。

当方は現時点で、この監視記録の対象から除外される Zero Data Retention（ゼロデータ保持）の適用を受けていません。

4.3 外国にある第三者への提供

上記処理者はいずれもアメリカ合衆国に所在します。また Cloudflare Workers は世界各地のエッジで実行されるため、処理が行われる国は要求ごとに異なります。

欧州経済領域（EEA）および英国から米国への移転については、各処理者が定める標準契約条項（Standard Contractual Clauses, GDPR Art. 46）またはこれと同等の仕組みに基づきます。各社が講じる保護措置の詳細は、それぞれのプライバシーポリシーをご確認ください。

5. 保管場所と保管期間

5.1 端末内のデータ

  • 半券の本文、題、要約、「判」、読み物、束の対応関係は、利用者の端末内にのみ保存されます。
  • 当方が保管期間を一方的に設定することはありません。
  • 本アプリをアンインストールすると、端末内のデータベースと預かりファイルは削除されます。OS の安全な保管領域に保存した設定・識別子も、OS の仕様に従って削除されます。

5.2 サーバー側

  • 当方のサーバーは、受け取った半券の本文・題・「判」・URL の内容を保存しません。
  • 無料枠の回数制限のため、ハッシュ化した端末識別子をキーとして、暦月（日本標準時）ごとの利用回数を Cloudflare Durable Object に保持します。このカウンタに本文は含まれません。
  • 短時間に集中した要求を抑えるため、ハッシュ化した識別子ごとの回数カウンタを同じく保持します。こちらは 1 分および 1 日の単位です。
  • 障害の把握のため、要求のパス、HTTP のステータス、エラーの種別、ハッシュ化した識別子、時刻を Cloudflare のログへ出力します。本文・題・「判」・URL は出力しません。

5.3 アプリ内の「すべて削除」の効果

本アプリの設定にある「すべて削除」を実行すると、端末内のデータベースから次のものが行ごと削除されます。削除済みの印を付けて扱いから外す方式ではありません。

  • 半券の本文と、本アプリがつけた題・要約・検索用の文
  • テーマのラベル、URL の参照、添付した画像の参照
  • 「判」、生成された読み物、「続きの種」、束の対応関係
  • 旧バージョンのチャット履歴

行を削除しただけでは、データベースファイルの未使用領域に本文の並びが残ることがあります。そのため本アプリは、行を削除するときに、その行が使っていた領域を 0 で塗ります。

あわせて、削除のあとにデータベースファイルそのものを書き直し、未使用領域を切り詰めます。この書き直しは、端末の空き容量が足りないなどの理由で失敗することがあります。失敗した場合は、次に削除を行うときに改めて試みます。書き直しが行われなかった場合でも、上記のとおり削除した行の領域は 0 で塗られています。

2026 年 9 月 22 日より前のバージョンでは、半券の本文・題・要約などに削除済みの印を付ける方式をとっており、これらの行はデータベースファイルの中に残っていました。その版から更新した場合、残っていた行は更新後の初回起動時に同じ方法で削除されます。

次のものは「すべて削除」の対象ではありません。

  • 端末内に残る操作の記録（削除および半券の種別変更・完了について、操作の種別、対象の識別子、件数、時刻）。本文・題・要約・テーマのラベル・URL は含みません。
  • OS の安全な保管領域に保存した設定、匿名の端末識別子、課金状態のキャッシュ。匿名の端末識別子は無料枠の回数制限（§5.2）に用いるため、残します。
  • 共有シートから受け取り、まだ半券にしていない預かりファイル（§5.1）。次に本アプリを開いたときに引き取られ、預かりファイルは空になります。

また、「すべて削除」を実行すると、本アプリが OS に予約していた通知はすべて取り消されます。

端末内のデータをすべて消去するには、本アプリをアンインストールしてください。当方のサーバーは §5.2 のとおり本文を保持していないため、当方に対する削除の請求は要りません。

6. 安全管理措置

  • 通信の暗号化: 端末と当方のサーバーの間、当方のサーバーと OpenAI 社の間、および当方のサーバーと §3.2 の宛先サイトの間の通信は、いずれも HTTPS（TLS）で暗号化します。
  • 端末内データの保護: 半券と読み物は端末内の SQLite データベースに保存されます。 本アプリは、このデータベースに独自の暗号化（SQLCipher 等）を適用していません。 保護は、利用者の端末の OS が備えるディスク暗号化（iOS の File Protection / Android の File-Based Encryption）に依存します。そのため、端末のロック画面のパスコードまたは生体認証を有効に設定し、OS を最新の状態に保つことを強く推奨します。
  • 設定・識別子の保護: アクセストークン、匿名の端末識別子、課金状態のキャッシュ、各種設定は、 OS が備える安全な保管領域（iOS の Keychain / Android の Keystore）に保存します。
  • アクセス制御: 当方のサーバーはアクセストークンを必要とし、トークンのない要求は受理しません（HTTP 401 を返します）。本文の大きさにも上限を設けています。
  • 識別子のハッシュ化: サーバー側で保持するカウンタとログの識別子は、 SHA-256 による一方向のハッシュ値であり、元の識別子を復元できません。
  • サーバー側のデータ最小化: 本文を保存しない設計により、サーバー側からの情報流出のリスクを小さくしています。
